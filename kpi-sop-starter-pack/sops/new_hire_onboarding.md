# New hire onboarding

| | |
|---|---|
| SOP ID | `new_hire_onboarding` |
| Owner | Ops manager |
| Time needed | about 120 minutes |
| Version | 1.0 |

## Purpose
Make a new hire productive in their first week.

## When to run it
A new team member's start date is confirmed.

## Tools you need
Shopify, email, chat, password manager, the KPI dashboard and SOP system

## Steps

- [ ] **1.** Create accounts with role-based access: Shopify, email, chat, password manager, dashboard.
  - Log: Access checklist
- [ ] **2.** Share the company overview, brand voice guide and product catalogue.
  - Log: Links shared
- [ ] **3.** Walk through the dashboard: what each KPI means and what the thresholds are.
  - Log: Walkthrough done
- [ ] **4.** Shadow each SOP assigned to the role once.
  - Log: SOPs shadowed
- [ ] **5.** Complete one SOP independently with a reviewer's sign-off.
  - Log: Reviewer sign-off
- [ ] **6.** Acknowledge each SOP in the SOP system.
  - Log: Acknowledgements
- [ ] **7.** Book the 30-day check-in.
  - Log: Calendar invite

## Done when
The new hire has completed one SOP independently and acknowledged all SOPs for their role.

## Escalate to
Founder, if the 30-day check-in raises concerns.
