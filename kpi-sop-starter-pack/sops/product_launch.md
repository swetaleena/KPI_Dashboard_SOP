# New product launch checklist

| | |
|---|---|
| SOP ID | `product_launch` |
| Owner | Founder |
| Time needed | about 90 minutes |
| Version | 1.0 |

## Purpose
Launch without broken pages, stockouts or unprepared support.

## When to run it
Manual. Start 7 days before a planned launch.

## Tools you need
Shopify admin, email platform, ad platforms, the KPI dashboard

## Steps

- [ ] **1.** Confirm the product page: photos, copy, size guide, price and shipping info.
  - Log: Page link
- [ ] **2.** Test checkout end to end on mobile with a real discount code.
  - Log: Test order number
- [ ] **3.** Confirm inventory counts and set the reorder point.
  - Log: Stock and reorder point
- [ ] **4.** Schedule email, SMS and social posts.
  - Log: Schedule links
- [ ] **5.** Brief support on FAQs, returns policy and macros.
  - Log: Brief sent
- [ ] **6.** Set launch ad budgets and creatives. Add UTM tags.
  - Log: Campaign names
- [ ] **7.** Add launch KPIs to the dashboard and book a 24-hour review.
  - Log: Calendar invite
- [ ] **8.** At 24 hours, review sales, conversion and issues. Decide what to change.
  - Log: Review notes

## Done when
Product is live, launch KPIs are on the dashboard, and the 24-hour review is complete.

## Escalate to
Founder decides on any go or no-go issue.
