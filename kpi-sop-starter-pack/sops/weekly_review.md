# Weekly performance review

| | |
|---|---|
| SOP ID | `weekly_review` |
| Owner | Founder |
| Time needed | about 45 minutes |
| Version | 1.0 |

## Purpose
Keep every KPI owned and every breach followed up.

## When to run it
Every Monday morning.

## Tools you need
The KPI dashboard, the task list

## Steps

- [ ] **1.** Open the dashboard and compare the last 7 days with the prior 7.
  - Log: Screenshot
- [ ] **2.** Review each KPI marked as a breach. Confirm an open task exists for it.
  - Log: Task links
- [ ] **3.** Review open tasks. Close, reassign or re-date anything overdue.
  - Log: Updated task list
- [ ] **4.** Review last week's experiment: result and decision.
  - Log: Decision
- [ ] **5.** Choose one priority and one experiment for this week.
  - Log: Written down
- [ ] **6.** Post the summary in the team channel.
  - Log: Message link

## Done when
Every red KPI has an owner and a date, and one priority and one experiment are chosen.

## Escalate to
Not applicable.
